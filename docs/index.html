よくある質問

無料で遊べる？ ダウンロードは必要？

無料・インストール不要でプレイできます。スマホとPCのブラウザに対応しています。通信費は利用環境によって発生します。

友達と別々のWi-Fiでも対戦できる？

オンラインマルチでルームを作成し、表示された招待リンクを友達に送ってください。相手もブラウザから参加できます。

最初の読み込みが遅いときは？

ゲームは無料サーバーを利用しているため、しばらくアクセスがないと休止します。最初の起動に約1分かかる場合があります。少し時間をおいて再読み込みしてください。

データは別のスマホへ引き継げる？

ゲーム内の一部の進行状況はブラウザ内に保存されます。別のブラウザや端末に自動では移らないため、ブラウザデータ削除には注意してください。

遊び方はかんたん。

  1. プレイヤー名と文字を設定
    使いたい1文字を5つのスロットに装備。全部ランダム設定も可能。
  2. 試合を開始
    CPU戦はすぐスタート。オンラインはルームへ参加し、ホストが開始。
  3. タップ／クリックで攻撃
    狙う方向へ攻撃。移動はスティック／WASD。最後まで生き残ろう。
公開ベータについて：無料サーバーは無通信が続くと休止するため、最初のアクセスに少し時間がかかる場合があります。ルームはサーバー再起動で消えることがあります。個人情報をプレイヤー名やルーム共有文に入力しないでください。
