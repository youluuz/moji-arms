### 登録型の無料配信・発見場所
- **GitHub Pages**：静的紹介ページ。Renderが休眠していてもゲームの魅力を案内し、プレイへ遷移できる。
- **itch.io**：ゲーム登録/開発日誌/タグでの発見を検討。ただしHTML5は静的配信で、Go対戦サーバーは別に必要。外部URLへの誘導や公開形式は規約を確認。
- **Foundplay**：ゲームが無料・ブラウザで実際に動く状態なら、無料の掲載/ローンチ申請も候補。申請の採否や表示は保証されない。
- **X / Bluesky / YouTube Shorts**：自分のアカウントで無償投稿。Bot連投、無断DM、コミュニティのルール違反はしない。

## 0円で見るべきKPI
**費用よりも継続率・遊びやすさを先に確認**。個人を追跡する外部解析ツールは導入せず、初期は任意アンケートと集計だけで十分。
- 友人テスト参加人数 / 2人対戦が開始できた割合
- 入室から試合開始まで詰まる操作
- 友達にすすめたいという感想の数
- 1週間以内に直せた不具合と、翌週の再プレイ意思

## 投稿・公開前の安全チェック
1. Render Liveで、CPU→オンライン→再戦まで手動テスト済み。
2. GitHub Pagesからの「プレイする」が実際の公開URLへ飛ぶ。
3. 動画・画像・BGMの利用権限を確認。
4. 文章に「必ず勝てる」「常時快適」「実測していない再生数/参加数」を書かない。
5. 不調時は投稿を見直し、ベータであることと改善予定を明記。
