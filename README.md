# 文字武装 GLYPH STRIKE v6.8 — 共通ロビー統合・CPUスマホ操作・全種類ランダム

## v6.8で更新した点

- **ログイン → 共通ロビー → モード選択 → 対戦**の流れに統合。オンライン対戦はトップページ内の埋め込み画面として開くので、ログイン・ロビーへ戻る際に最初からやり直さずに済みます。
- CPU通常・CPUカスタムの両方をスマホ向けに更新。**画面左の任意の場所をドラッグして移動、右の戦場をタップして選択スロットをその方向に発動**。縦・横の向きでカメラ表示範囲と解像度を変更します。
- CPUとオンラインの文字ランダムを、漢字だけでなく、ひらがな・カタカナ・英数字・記号・絵文字を含む広いUnicode文字集合に拡張しました。カテゴリを先に選ぶため、種類による極端な抽選偏りも抑えます。すべてのUnicode文字が端末に表示できる保証はありません。
- 共通ロビー内に「ルームを作成」「ランダムマッチ」「コードで参加」を配置。マルチ用フレームからは共通ロビーへ直接戻れます。
- **知らないプレイヤーとのランダムマッチは引き続きホストの手動開始**です。自動で戦闘開始しません。
- 旧CPU画面とマルチ画面・共通ロビーの主要な結合ポイントについてGo回帰テストを追加。

**注意**：GitHubへの反映とJavaScript構文確認を行っていますが、実際のRender上への反映、別Wi-Fi同士のオンライン対戦、iOS/Androidのタッチ・縦横切替の実機検証は未完了です。Renderが更新をデプロイすると、ルートURLからログインして試せます。

## v6.7: スマホの操作改善と自由な文字選択

- スマホでは戦場**左35%の好きな場所を長押し・ドラッグして移動**。移動パッドは指の位置に現れます。
- **戦場右側の狙った位置をタップ**すると、現在選択中のスロットを一度だけ発動。攻撃・貫通・ホーミングはタップ方向へ飛び、防御・回復は自分に発動。右側の発動ボタンは不要です。
- タップ専用WebSocket命令を実装。タップ直後に指を離しても、50ms間隔の移動入力に発動がかき消されません。
- 画面の縦横比に合わせたカメラへ変更。縦画面では縦長の戦場を描画し、横画面では横長表示。高DPI表示にも対応。
- スロット切替ボタンを毎フレーム作り直さず、押しっぱなし・タップを維持しやすくしました。
- 通常オンラインも**漢字・絵文字・英数字・記号から1文字（絵文字1個）**を選択できます。文字の数値はサーバーと同じルールで計算します。
- 「絵文字入力例」ボタン、漢字5枠ランダム、絵文字5枠ランダムを追加。
- 対戦のランダムマッチは引き続き**ホストが手動開始**する仕様です。

**検証範囲：** JavaScript構文チェック済み。Go回帰テストはRenderのDockerビルド時にも実行されます。実機のタッチ操作や縦横回転、別Wi-Fi対戦の最終確認が必要です。



## v6.6: ランダムマッチ・文字ランダム

- **通常マルチ**のオンライン装備確認ページで「🌐 ランダムマッチ」を選ぶと、他のプレイヤーが待機中の公開ルームに参加します。待機中の部屋がなければ自動で募集ルームを作成します。
- **人数が2人以上になっても自動で試合は開始しません。** 募集ルームのホストが「ランダム対戦を開始（ホスト）」を押すまで待機します。最大10人まで合流できます。
- 通常の「新しいルームを作る」「コードで参加」は引き続き利用可能です。ランダムマッチは通常モード専用です。
- オンライン装備ページの「🎲 5枠の文字をランダム」で、5文字を重複なくランダム設定します。各枠の「🎲 文字ランダム」で1文字だけ引き直せます。能力タイプは変更されません。
- ランダム文字は同梱の漢字画数辞書から選び、通常マルチでは正しい画数が自動反映されます。
- RenderのDockerビルドではGoテストを実行します。リアルな2回線間での通信試験やスマホ操作の動作確認は別途必要です。

## 遊ぶ方法

### 全員がブラウザで遊ぶ公開版（おすすめ）

このフォルダをGitHubのリポジトリに公開し、`render.yaml`をRenderに連携すると、**誰でもアクセスできるHTTPSのゲームURL**が生成されます。公開に **Python、WindowsのEXE、Cloudflareの一時URL** は不要です。

1. GitHubに新しいリポジトリを作成（例 `moji-arms-online`）。
2. **このフォルダの中身**（`main.go`, `tunnel.go`, `go.mod`, `main_test.go`, `public/`, `Dockerfile`, `render.yaml`）を、GitHubリポジトリの **ルート** に配置してコミットする。ZIPファイル1つだけのアップロードではWebアプリは起動しません。
3. https://dashboard.render.com/ を開き、**New → Blueprint** を選び、GitHubのリポジトリを接続する。
4. `render.yaml` を認識させて **Deploy Blueprint** を実行。無料枠の利用条件や料金確認画面が表示された場合は、内容を確認する。
5. デプロイが `Live` になったら、Renderが表示する `https://...onrender.com/` がみんなで遊べるゲームURLです。
6. ゲームで名前を入力しロビーへ → **「ルームを作成して開く」** → 友達に招待URLを送信。相手は別Wi-FiでもWebブラウザで参加できます。

**注意：このZIP自体はオンラインで公開されたサイトではありません。** GitHub/Renderへのアップロードとデプロイを完了するまで、固定の公開URLは存在しません。

### Windowsで一時公開する場合

`文字武装_別WiFi対戦_Windows.exe` をダブルクリックすると、一時的なCloudflare Quick TunnelのURLを発行する方法も利用できます。外部サービスとの接続および初回ツール取得が必要で、通信が遮断される環境では発行できません。公開URLが変わるため、**広く配布するゲームのURLにはRender版をおすすめします**。

### 同じWi-Fiのみ

`文字武装_起動_Windows.exe` をダブルクリック。Windows 10/11 x64向け。Python不要。起動した黒い画面を閉じるとサーバーが停止します。

## 運用上の注意

- 現在のログインはゲスト名登録であり、パスワード・本人認証はありません。
- ガチャ・実績の所持データは **プレイヤーのブラウザのローカル保存** です。PCやドメインを変えると引き継がれません。ブラウザのデータを削除すると失われます。
- 試合とルームのデータは稼働中サーバーのメモリ内にあります。再起動・無料枠の休止で消えます。Render無料Webサービスは無通信15分で休止することがあり、起動直後に時間がかかる場合があります。
- 公開ゲームを長く運営するなら、永続DB、アカウント認証、チート対策、通報や利用ルールなどを追加してください。現状は小規模・友人間対戦向けです。
